# 🚂 Төмөр замын сургалтын платформ

Монгол Улсын төмөр замын техник ашиглалт, дохиолол холбоо, хөдөлгөөний удирдлагын журмын интерактив сургалтын систем.

## 🌐 Demo
Одоогийн веб хувилбар: `index.html` файлыг browser-ээр нээнэ.

## 📚 Бүлгүүд
- **Техник ашиглалтын журам** — 15 бүлэг
- **Дохиолол, холбооны журам** — 9 бүлэг  
- **Хөдөлгөөний удирдлагын журам** — 16 бүлэг

## ✨ Онцлог
- Интерактив карт, SVG дүрслэл
- Тохирол тоглоом, тест
- Хэрэглэгчийн бүртгэл, медалийн систем
- Админ дашбоард

## 🛠️ Технологи
- Frontend: HTML5, CSS3, JavaScript (React руу шилжих төлөвлөгөөтэй)
- Backend: Node.js + Express (төлөвлөгөөнд)
- Database: PostgreSQL (төлөвлөгөөнд)

## 📁 Бүтэц
```
tumur-zam-surgalt/
├── frontend/
│   ├── public/
│   │   └── index.html        # Одоогийн бүрэн хувилбар
│   └── src/
│       ├── components/        # React компонентууд
│       ├── pages/             # Хуудаснууд
│       └── admin/             # Админ хэсэг
├── backend/
│   └── src/
│       ├── routes/            # API endpoints
│       └── models/            # Database models
└── docs/                      # Баримт бичиг
```

## 🚀 Суулгах

### Одоогийн хувилбар
```bash
git clone https://github.com/YOUR_USERNAME/tumur-zam-surgalt.git
cd tumur-zam-surgalt/frontend/public
# index.html-г browser-ээр нээнэ
```

### Хөгжүүлэлт (ирээдүй)
```bash
cd backend
npm install
npm run dev

cd frontend
npm install
npm start
```
